02 / The problem Why this exists

Multi-agent systems fail
in two predictable ways.

Failure mode 01

Infinite loops.

A Coder agent keeps "fixing" the same thing. A Reviewer keeps asking for the same change. The loop looks like progress to a step counter, but it's silently burning $400 an hour.

Failure mode 02

Corrupted handoffs.

Agent A sends unstructured markdown when Agent B expects JSON. The pipeline crashes, or worse, silently drops context.

Both cost real money. Neither is solved by prompt engineering.

03 / The solution

Three things, sitting
between your agents.

01

Schema shield.

Every handoff validated against a strict Pydantic contract before it reaches the next agent. Malformed payloads are rejected at the door with a structured HTTP 422.

02

Loop detection.

SHA-256 fingerprinting of every payload. Identical repeats trip the breaker. A↔B ping-pongs trip the breaker. Step counters catch the rest.

03

Runtime breaker.

When thresholds are breached, the response carries structured diagnostics. Your orchestrator decides what to do — halt, alert, or escalate.

05 / How it works

Five lines to add it
to your orchestrator.

your_orchestrator.py Python 
from agenttrafficcop import Guard, LoopDetected

guard = Guard(url="http://localhost:8000", api_key="your-key")

try:
    result = await guard.check(
        session_id="run-42",
        sender="coder",
        recipient="reviewer",
        payload={"diff": "fix typo"},
    )
    print("approved at step", result.step)
except LoopDetected as e:
    print("loop caught:", e.error_code)

Works with LangGraph, CrewAI, AutoGen, or raw asyncio. Runs as a standalone service — call it before any handoff.
