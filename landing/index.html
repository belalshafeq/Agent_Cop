01 — Features

Three primitives,
sitting between your agents.

01

Schema shield

Every handoff validated against a strict Pydantic v2 contract before it reaches the next agent. Malformed payloads are rejected at the door.

02

Loop detection

SHA-256 fingerprinting on every payload. Identical repeats and A↔B ping-pongs trip the breaker. Step counters catch the rest.

03

Circuit breaker

When thresholds breach, the response carries structured diagnostics. Your orchestrator decides: halt, alert, or escalate.

02 — How it works

Five lines to add it
to your orchestrator.

your_orchestrator.py Python
from agenttrafficcop import Guard, LoopDetected guard = Guard(url="http://localhost:8000", api_key="your-key") try: result = await guard.check( session_id="run-42", sender="coder", recipient="reviewer", payload={"diff": "fix typo"}, ) print("approved at step", result.step) except LoopDetected as e: print("loop caught:", e.error_code)

Runs as a standalone FastAPI service. Works with LangGraph, CrewAI, AutoGen, or raw asyncio. The SDK ships a LangGraph adapter — wrap any node in one line.
