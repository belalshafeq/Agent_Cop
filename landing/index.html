what it does

three things,
sitting between
your agents.

[01]

schema shield

every handoff validated against a strict pydantic contract. malformed payloads get a structured 422 before reaching the next agent.

[02]

loop detection

sha-256 fingerprinting on every payload. identical repeats trip the breaker. a↔b ping-pongs trip the breaker. step counters catch the rest.

[03]

runtime breaker

thresholds breach → response carries structured diagnostics. your orchestrator decides: halt, alert, or escalate.

integration

five lines to
add it to your
orchestrator.

your_orchestrator.py python
from agenttrafficcop import Guard, LoopDetected   guard = Guard(url="http://localhost:8000", api_key="your-key")   try: result = await guard.check( session_id="run-42", sender="coder", recipient="reviewer", payload={"diff": "fix typo"}, ) print("approved at step", result.step) except LoopDetected as e: print("loop caught:", e.error_code)

works with langgraph, crewai, autogen, or raw asyncio. runs as a standalone service — call it before any handoff.
