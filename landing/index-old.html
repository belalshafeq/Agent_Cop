02
The problem

Multi-agent systems fail
in two predictable ways.

🔁

Infinite loops

A Coder agent keeps "fixing" the same thing. A Reviewer keeps asking for the same change. The loop looks like progress to a step counter, but it's silently burning $400 an hour.

💥

Corrupted handoffs

Agent A sends unstructured markdown when Agent B expects JSON. The pipeline crashes, or worse, silently drops context.

Both problems cost real money. Neither is solved by prompt engineering.

03
The solution

Three things, sitting
between your agents.

🛡

Schema shield

Every handoff validated against a strict Pydantic contract before it reaches the next agent. No malformed payloads. No silent failures.

🔍

Loop detection

SHA-256 fingerprinting of every payload. Identical repeats and A↔B ping-pongs trip the breaker. Step counters catch the rest.

⚡

Runtime breaker

When thresholds are breached, returns HTTP 422 with structured diagnostics. Your orchestrator decides what to do.

04
How it works

Five lines to add it
to your orchestrator.

your_orchestrator.py Python 
from agenttrafficcop import Guard, LoopDetected

guard = Guard(url="http://localhost:8000", api_key="your-key")

try:
    result = await guard.check(
        session_id="run-42",
        sender="coder",
        recipient="reviewer",
        payload={"diff": "fix typo"},
    )
    print("approved at step", result.step)
except LoopDetected as e:
    print("loop caught:", e.error_code)

Works with LangGraph, CrewAI, AutoGen, or raw asyncio. The middleware runs as a standalone service — call it before any handoff.
