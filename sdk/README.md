# AgentTrafficCop SDK

[![PyPI version](https://img.shields.io/pypi/v/agenttrafficcop.svg)](https://pypi.org/project/agenttrafficcop/)
[![Python versions](https://img.shields.io/pypi/pyversions/agenttrafficcop.svg)](https://pypi.org/project/agenttrafficcop/)

The official Python SDK for **AgentTrafficCop** — a runtime circuit breaker and schema shield for multi-agent systems.

Stop your AI agents from burning money in infinite loops. This SDK allows you to route agent-to-agent handoffs through the AgentTrafficCop SaaS for validation, hashing, and loop detection.
